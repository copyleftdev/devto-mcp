# Privacy Policy

**Last updated:** 2026-09-13

`devto-mcp` runs on your machine. It is a local program that your MCP client starts and stops;
there is no service behind it and no account with its author.

## What it collects

Nothing. The author of this software receives no data from it — no telemetry, no analytics, no
crash reports, no usage counts. There is no server to send any to.

## What leaves your machine

Only requests to the DEV API, over HTTPS, to the instance you point it at (`https://dev.to` by
default, changed with `DEVTO_BASE_URL`). Those requests carry:

- what a tool needs in order to work — an article id you asked to read, the draft text you
  asked to publish, a search term you supplied
- your API key, in the `api-key` header, when one is configured

Nothing is sent anywhere else. There are no third-party services, no CDNs at runtime, and no
outbound connections other than to the instance you configure. The CMUdict and hyphenation
datasets the text tools need are compiled into the binary, so even those fetch nothing.

The four offline tools — `validate_draft`, `analyze_readability`, `analyze_structure` and
`forem_reading_time` — make no network request at all. Draft text handed to them never leaves
the process.

## What it stores

Nothing on disk. The server writes no files, no logs, no configuration and no cache to your
filesystem.

A small response cache is held **in memory** so that re-reading the same thing twice in one
turn does not spend the rate budget twice. It exists only while the process runs and is gone
when it exits.

## Your API key

It is read from the `DEVTO_API_KEY` environment variable, kept in memory, and sent only to the
DEV instance as an `api-key` header. It is never written to disk and never printed: the
startup line reports *whether* a key is present, never its value.

The key is yours, generated by hand at dev.to/settings/extensions. Revoke it there at any time
and this software loses all access immediately.

## Data handled on your behalf

When you use a write tool, your article content goes to DEV and becomes subject to
[DEV's own privacy policy](https://dev.to/privacy) and terms. This software is not affiliated
with DEV or Forem; it is an independent client of a public API.

Note that DEV has no delete endpoint. A published article can be unpublished through this
software, but not removed — that is a property of the platform, not of this client.

## Retention and deletion

There is nothing to retain and nothing to delete. Stop using the software, or remove the
binary, and no data about you exists anywhere in it. To remove data you have published, use
DEV directly.

## Children

This software is a developer tool and is not directed at children.

## Changes

Changes to this policy are published in this file, in the repository, with the date above
updated. The version you are subject to is the one shipped with your copy.
