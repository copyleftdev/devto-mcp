# Assets

`cover.png` — 1000×420, the dimensions DEV recommends for an article cover. DEV cannot accept
an uploaded image through any API version, so a cover has to already be hosted somewhere
public; this file is here to give it a stable raw URL:

```
https://raw.githubusercontent.com/copyleftdev/devto-mcp/main/docs/assets/cover.png
```

The 840px crop DEV uses for `og:image` takes the left five-sixths, so nothing that has to
survive sharing sits in the right-hand sixth.
